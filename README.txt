MIJN 4-WEKEN APP

Bestanden:
- index.html: de app
- manifest.webmanifest: maakt installeren op beginscherm mogelijk
- sw.js: offline cache
- icon.svg: app-icoon

Snel testen:
Open index.html op een computer. Voor volledige PWA-installatie op je telefoon moet de map via HTTPS worden gehost.

Gratis hosten:
1. Maak een gratis GitHub-account als je dat nog niet hebt.
2. Zet deze vier bestanden in een nieuwe repository.
3. Schakel GitHub Pages in via Settings > Pages.
4. Open de GitHub Pages-link op je telefoon.
5. iPhone Safari: Deel > Zet op beginscherm.
   Android Chrome: menu > App installeren / Toevoegen aan startscherm.

Privacy:
De app gebruikt localStorage. Vinkjes, notities, boodschappen en metingen blijven lokaal in de browser op het toestel waarop je de app gebruikt.
